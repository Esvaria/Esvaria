### 🔧 What I work on
- **[citiwatts.eu](https://citiwatts.eu)** — An open-source GIS platform for energy planning (heating, cooling, mobility, sector coupling). Built on the H2020 Hotmaps foundation, now evolved into a deployment-ready tool used across Europe. 
- **OpenGIS4ET** — ERA-NET project that brought citiwatts from TRL 7 to 8, validated through case studies in Denmark, Austria, Switzerland, and Germany.
- **Hydrolab** - Inventory management platform
